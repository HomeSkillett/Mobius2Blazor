Gauge Data Templates

Source: GaugeDataTemplates.xaml — Registry that maps ViewModel types to gauge DataTemplates. Used by DisplayGaugePanel and EditableGaugePanel to resolve which visual to render for each gauge cell.

Template → Gauge Mapping

Each row maps a DataTemplate key to the gauge control it instantiates. "MT" = has a MultiThreadVisual variant for off-thread rendering.
